# AI Financial Expense Analyzer

## 📌 Overview

AI Financial Expense Analyzer is a web application designed to help users track, categorize, and analyze their personal expenses. The project aims to provide clear financial insights and AI-powered recommendations for better budgeting and financial decision-making.

---

## 🎯 Features

- Add income and expenses
- Categorize transactions
- View spending summaries
- Visualize financial data with charts
- Receive AI-generated financial insights
